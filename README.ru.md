# Codex Weekly Limit Tray

Небольшое нативное приложение для Windows, которое показывает ваш недельный лимит Codex в системном трее.

На значке в трее отображается крупное жирное число, например `73`, или `--`, пока данные о лимите недоступны. Щёлкните по значку, чтобы открыть панель Codex. В панели показаны остаток, время сброса и время до сброса.

## Что нужно

- Windows 10 или Windows 11 на x64
- Официальный [Codex CLI](https://developers.openai.com/codex/cli/)

Для сборки из исходного кода установите компилятор C++ из MSYS2 UCRT64. Скрипт сборки сначала проверяет `%USERPROFILE%\msys64\ucrt64\bin\g++.exe`, затем `C:\msys64\ucrt64\bin\g++.exe`, либо использует полный путь, переданный через переменную окружения `CXX`.

Приложение находит Codex через пользовательскую известную папку Windows Local AppData. Её обычное расположение:

```text
%LOCALAPPDATA%\Programs\OpenAI\Codex\bin\codex.exe
```

## Запуск приложения

Для публичного релиза распакуйте ZIP-архив и запустите `CodexWeekUsageTray.exe`.

Сборка и запуск из исходного кода:

```powershell
native\build.cmd
native\out\CodexWeekUsageTray.exe
```

Значок располагается в обычном системном трее Windows. Он никогда не перекрывает часы или дату.

### Как сделать значок в трее видимым

1. Запустите `CodexWeekUsageTray.exe`.
2. Откройте **Параметры > Персонализация > Панель задач > Другие значки в системном трее**.
3. Найдите **CodexWeekUsageTray** и включите его (**Вкл**).

После этого Windows будет показывать значок в системном трее, а не скрывать его в списке переполнения.

## Работа с панелью

- **Левый щелчок по значку в трее** — открыть или скрыть панель с подробностями.
- **Правый щелчок по значку в трее**, затем **Show panel** — открыть панель из меню трея.
- **Refresh** — проверить лимит прямо сейчас.
- **Close** — скрывает только панель. Приложение в трее продолжает работать.
- **Sign in** — при необходимости открывает официальную страницу входа Codex ChatGPT в браузере по умолчанию.
- **Check** — повторно проверяет учётную запись после входа.

Приложение обновляется сразу, как только Codex присылает обновление лимита. В качестве запасного варианта оно также выполняет проверку не чаще одного раза в пять секунд.

## Проверки сборки

```powershell
native\build.cmd tests
native\out\CodexWeekUsageTrayTests.exe
native\out\CodexWeekUsageTray.exe --self-test
```

## Удаление сохранённых записей в трее

Если после тестирования в разделе **Другие значки в системном трее** остались старые копии, дважды щёлкните `uninstall.cmd` в той же папке, где находится `CodexWeekUsageTray.exe`. Очистка начинается сразу: ничего вводить не нужно, подтверждения не запрашиваются.

`uninstall.cmd` останавливает подходящие процессы `CodexWeekUsageTray.exe` и удаляет только их настройки трея для текущего пользователя. Это удобно перед заменой старого релиза или когда остались дублирующиеся записи в трее. Он никогда не удаляет EXE-файлы и не меняет настройки трея других приложений.

Из терминала в папке релиза можно также выполнить:

```powershell
.\CodexWeekUsageTray.exe --uninstall-dry-run
.\CodexWeekUsageTray.exe --uninstall
```

Пробный запуск только перечисляет точные записи `CodexWeekUsageTray.exe` и ничего не изменяет.

## Безопасность и конфиденциальность

- Приложение не читает, не выводит, не сохраняет и не передаёт ваш пароль, API-ключ, refresh-токен или историю использования.
- URL для входа открывается в браузере по умолчанию, только если он использует HTTPS и хост в точности равен `chatgpt.com` или `auth.openai.com`.
- В нативном хосте нет апдейтера, загрузчика, регистрации в автозапуске и собственного сетевого клиента. Трафик учётной записи Codex CLI обрабатывает самостоятельно через локальное stdio-соединение.
- EXE-файлы релизов пока не подписаны Authenticode. Перед запуском загруженного файла сверьте опубликованное значение SHA-256.

Релизы v2.0.1 и новее включают EXE, `uninstall.cmd` и соответствующий манифест `SHA256SUMS`. Архив не содержит среды выполнения .NET, DLL или PDB. В v2.0.0 был только EXE.

Приложение хранит текущий лимит только в памяти. Windows может сохранять обычные настройки значков уведомлений, а Codex CLI хранит собственные данные сессии.
